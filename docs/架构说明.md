# 架构说明

浏览器只访问 Nginx。Nginx 将聊天转发给 Open WebUI，将 `/api/agent/` 转发给 Agent Core，并从只读挂载的共享文件目录提供 `/artifacts/` 下载。

Agent Core 对 Open WebUI 暴露 OpenAI Compatible `/v1/models` 与 `/v1/chat/completions`，内部调用现有模型 API。Agent Loop 支持 `system/user/assistant/tool`、原生 `tool_calls` 与严格 JSON 回退，默认最大 10 步、工具超时 120 秒，同一参数重复调用超过两次会被阻止。

所有代码执行和文件操作均发生在 Tool Runner；Office 生成与 LibreOffice 验证发生在 Office Worker。二者共享 `/workspace`，Agent Core 不执行用户代码。PostgreSQL 保存 Open WebUI 业务数据，Qdrant 作为本地向量数据库准备。所有内部组件使用 `offline-ai-net` 服务名互访。

模型服务是外部只读依赖，`MODEL_RUNTIME_MANAGED=false`。平台不挂载模型权重、不接管启动命令、不修改上下文长度或 Tool Calling Parser。
