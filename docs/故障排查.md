# 故障排查

先运行：

```bash
./status.sh
./healthcheck.sh
./logs.sh all
```

模型 API 失败时，在宿主机执行 `curl http://127.0.0.1:6215/v1/models`，再从 Agent Core 容器执行相同测试（地址使用 `.env` 中的 `MODEL_BASE_URL`，无需 Authorization）。宿主机 `127.0.0.1` 在容器中必须转换为 `host.docker.internal`。

Office 失败时查看 `./logs.sh office`，检查 `libreoffice --headless --version` 和 `fc-list :lang=zh`。文件写入失败时检查 `.env` 中 `${DATA_ROOT}/files` 的 UID/GID 与权限。

Open WebUI 启动但没有模型时，检查 Agent Core `/v1/models`、`OPENAI_API_BASE_URL=http://agent-core:8000/v1` 及数据库中是否持久化了旧连接。恢复或改配置前先运行 `./backup.sh`。
