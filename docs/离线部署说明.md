# 离线部署说明

联网准备环境按目标架构运行 `TARGET_ARCH=arm64 ./prepare-offline-bundle.sh` 或 `TARGET_ARCH=amd64 ./prepare-offline-bundle.sh`；目标服务器只运行 `sudo ./deploy.sh`。目标服务器必须预装 Docker、Docker Compose、bash、curl、jq、openssl、zstd、tar 和 sha256sum；部署前检查会逐项明确报告缺失命令。

部署脚本在导入镜像前执行 `sha256sum -c checksums.sha256`，任何不一致都会中止；随后根据包内 `TARGET_ARCH` 核对服务器与逐个镜像的 Architecture，架构不一致会中止。Compose 使用 `--pull never --no-build`，因此不会联网拉取或构建。

部署参数统一放在 `config/deployment.env`（可从 `.example` 复制），也可用 `deploy.sh` 命令行参数覆盖。`WEB_PORT` 指定首选端口；`WEB_PORT_CONFLICT_POLICY=next` 会检查主机监听状态并自动递增，`fail` 则立即停止。模型 URL、模型完整名称、可选 API Key、持久化目录、监听地址、时区、安全开关、资源上限及预检阈值均可配置。

默认不扫描或修改模型 Runtime。需要只读自动探测时设置 `MODEL_AUTO_DETECT=true`；未启用时严格使用 `MODEL_BASE_URL` 和 `MODEL_NAME`。持久化目录必须是至少两级的专用绝对路径，危险系统路径会被拒绝。
